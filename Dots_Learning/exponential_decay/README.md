# 指数衰减：用半衰期表达“越近越重要”

学习记录：2026-11-13。全部行为均为合成示例。

## 从硬窗口到软记忆
滑动窗口把边界外的事件直接移除。指数衰减没有硬截止：一个事件距今 Δt，其权重为：

`weight = 2^(-Δt / H)`

H 是半衰期，时间单位须与 Δt 一致。过去 H 后贡献减半，再过 H 后变成 1/4。它表达平滑的新近性，不代表概率或已经校准的置信度。

## 鞋与包的例子
半衰期 H=5 分钟，10:00 点鞋、10:04 点包、10:08 点鞋。10:10 查询：

- 鞋：`2^(-10/5) + 2^(-2/5) = 0.25 + 0.7579 ≈ 1.01`。
- 包：`2^(-6/5) ≈ 0.44`。
- 同一例子的 10 分钟硬窗口是鞋 1、包 1。两者回答的问题不同，不是哪个计数“算错”。

## 增量维护
每个品类只保存 (上次分数 S, 更新时间 t)。在新时间 now：

`S_now = S * 2^(-(now-t)/H)`

写入时先衰减，再加新事件权重；查询时先衰减到查询时间，再读分数。分数是历史贡献之和，共同乘上同一衰减系数即可，不需要保存全部事件。重复查询同一时间不再衰减；分两段衰减与直接衰减到终点等价。

[实现](solution.py) 使用 Python 标准库，add 更新一个品类 O(1)，query 返回所有 C 个品类 O(C)，状态空间 O(C)。只支持时间单调不减的事件和查询，拒绝回拨与非有限时间；乱序与多线程是后续问题。

## 边界与代价
- 没有硬截止，所以长时间不活跃品类仍可能占状态。极小分数裁剪会引入近似误差，需要明确阈值；本例不自动裁剪。
- 很长时间后浮点数可能下溢为 0，这是数值精度限制，不是理论上的硬窗口。
- H 越小响应越快、也更易受短期波动影响；越大记忆越长。
- 频次、事件权重和半衰期共同影响分数，不能把分数大小直接解释为意图是否改变。

## 可继续练习
同一个事件序列试 H=2、5、20，比较瞬时兴趣与稳定兴趣的差别。用回放确定适合目标的尺度，而不是把教学参数当成通用最优值。
