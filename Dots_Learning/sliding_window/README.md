# 滑动窗口与单调队列

学习记录：2026-11-13

## 问题
给出序列与窗口大小 k，返回每个完整窗口的最大值。
例如 `3, 1, 4, 2, 5`，k=3，答案是 `4, 4, 5`。
朴素方法对每个窗口扫描 k 项，时间 O(nk)。

## 核心直觉
窗口定义哪些元素还有效；单调队列只保留仍可能成为最大值的候选。
队列存下标而非值，便于判断过期。下标递增，对应值严格递减：

1. 队首下标 ≤ i-k 时，移除过期项。
2. 从队尾删除值 ≤ 新值的候选。
3. 新下标入队；形成完整窗口后，队首就是最大值。

为什么能删除？新值至少一样大，且更晚过期。旧候选还有效时，新值一定也有效，因此旧候选不会再成为必要的答案。相等时保留较新的下标即可。

## 复杂度
每个元素最多入队一次、出队一次，总时间 O(n)，候选队列空间 O(k)；返回的答案另占 O(n)。单次更新可能连续弹出多项，O(1) 是摊还而非单次最坏复杂度。

[Python 实现](solution.py) 接收可索引数值序列与正整数 k。k≤0 抛错；空序列或 k 大于序列长度返回空列表。注意相等值、负数、递增/递减序列、k=1。

## 与流式频次的区别
单调队列维护的是最大值，不是出现次数。低频品类以后可能成为高频，不能像队尾候选一样直接丢弃其所有事件。下一步见 [流式窗口计数](../streaming_counts/README.md)。
